# Tienda de Refacciones de Computadora

Sistema CRUD para administrar el inventario de una tienda de refacciones de computadora.

**Autor:** Pedro Lantigua
**Materia:** Programación III
**Profesor:** Kelyn Tejada

## Cómo ejecutar el proyecto

1. Clonar el repositorio: `git clone https://github.com/PedroL2022/Tienda_Refaciones_computadora.git`
3. Entrar a la carpeta del proyecto: `cd Tienda_Refaciones_computadora`
4. Ejecutar: `dotnet run` o depurador del mismo vsStudio arriba el botoncito verde
5. Abrir en el navegador: `http://localhost:5292`

Ramas de trabajo:

- **feature/setup-database:** configuración de la base de datos.
- **feature/model:** modelos Producto y Categoria.
- **hotfix/categoria:** corrección del modelo Categoria cometi un error a la hora de crearlo.
- **feature/list:** listado y detalle de productos.
- **feature/create:** agregar productos.
- **feature/update-delete:** editar, eliminar y resumen del inventario para completar el crud.
